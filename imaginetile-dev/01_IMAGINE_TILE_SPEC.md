# 🛸 01. 『IMAGINE TILE（イマジンタイル）』完全実装仕様書＆ゲームルール

## 1. ゲーム概要とプレイモード体系
『IMAGINE TILE』は、ズーム・ぼかし・色相変化・反転・位置ズレなどの視覚デバフがかかった画像（または動画）を覆うタイル壁を、ホバーカーの武装（SHOT / CANNON / SPECIAL）で破壊し、30秒以内に隠された答えを導き出すSFクイズアクションゲームです。

### 編成スタイル＆オンライン協力マルチプレイ（Play Style）
タイトル画面の `#playstyle-row` または5機のホバーカーアイコン（`#intro-cars`）から、以下の4スタイルをすべてのゲームモード（NORMAL / HYPER / ENDLESS / CUSTOM）で選択できます：
- **👥 全5機 (`playStyle = 'team'`, `numPlayers = 5`)**：1人で5機のホバーカー（PILOT / ENGNR / HACKER / SNIPER / LEADER）を切り替えながら戦うフル編成モード。
- **👤 1機 (`playStyle = 'solo'`, `numPlayers = 1`)**：5機の中から好きな1機（`soloUnit = 0..4`）を選んで単独で挑むモード。エネルギーとタイルコアが1機に集中（5倍相当）するため、毎問ダイナミックにSPECIALやCANNONを撃ち込める爽快なプレイフィールを持ちます。
- **🛸 自由編成 (`playStyle = 'custom_units'`, `numPlayers = 1..5`)**：タイトル画面の5機のホバーカーをクリックして出撃ON/OFFを切り替え、2機や3機など好きな組み合わせで出撃できるオフラインモード。出撃機体数に応じて初期EN・クリアEN・回答コスト・コア倍率・突破ボーナスが自動分配されます。
- **🌐 ONLINE MULTI（P2P 2〜5人オンライン協力マルチプレイ）**：
  - 6文字の部屋コード（PeerJS WebRTC ＋ 同一ブラウザ内 `BroadcastChannel` 自動高速通信対応・サーバー維持費ゼロ）で2〜5人の仲間と協力出撃するモード。
  - **機体重複なし（再クリック解除＆入れ替え対応）**：5機（`unitIdx: 0..4`）から各プレイヤーが重複なしで1機を選択。自分が搭乗中の機体をもう一度クリックすると搭乗解除（未選択状態 `unitIdx = -1`）できるため、**5人満員の部屋でも機体の入れ替えが可能**です。全員がいずれかの機体に搭乗し「準備完了（READY）」になるとホストが出撃を開始できます。
  - **リアルタイム非停止タイマー**：誰かが回答を入力・発射している最中やポーズ画面を開いている間も30秒タイマーは停止せず、仲間は同時にタイル攻撃や別回答を継続できます。
  - **途中切断時の自動引き継ぎ安全装置**：万が一バトル中にゲストの通信が切断された場合でも試合は強制終了せず、切断された機体の操作権をホストが自動的に引き継いで（`controlledByHost = true`）最後までプレイを続行できます。

### 4つのゲームモード
1. **▶ NORMAL MODE（全10問）**：
   - 盤面サイズ推移：Q1〜Q3 `7×7` (Lv1) ➔ Q4〜Q6 `8×8` (Lv2) ➔ Q7〜Q9 `9×9` (Lv3) ➔ Q10 `10×10` (FINAL / ヒント `???`)。
2. **⚡ HYPER MODE（全10問）**：
   - 盤面サイズ推移：Q1〜Q3 `8×8` (Lv2) ➔ Q4〜Q6 `9×9` (Lv3) ➔ Q7〜Q9 `10×10` (Lv4) ➔ Q10 `15×15` (CHAOS FINAL / ヒント `???` / 真っ黒パレット)。
3. **∞ ENDLESS MODE（無限ステージ）**：
   - Q1〜Q2は `7×7` から始まり、2問クリアするごとに盤面が `+1×1` 拡大（`sz = 7 + Math.floor(step / 2)`）。
   - Q9（`step >= 8`, `11×11`）から深黒パレットに突入し、Q31（`step >= 30`）以降はヒントが `???` になります。
4. **🛠 CUSTOM MODE（ステージ＆グリッドビルダー）**：
   - 最大10ステージまで、各ステージの「問題数（1〜50問）」「盤面サイズ（`1×1`〜`100×100`）」「ステージ妨害ギミック（⚡CYBER / 🌊OCEAN / 🌿JUNGLE / 🎲RANDOM / 🚫OFF）」を自由に設計可能。オンラインロビーからもホストがCUSTOM構成を編集・出撃できます。

## 2. エネルギー（pt）＆回答コスト＆タイルコア（💎）の数理仕様

ゲーム内のすべてのリソースは **「1💎（タイルコア） ＝ 3pt（エネルギー） ＝ 3タイル破壊」** の完全等価レートで設計されています。

| リソース・コスト項目 | 数式（出撃機体・プレイ人数 $P \in \{1..5\}$、盤面一辺 $N$） | デフォルト値・備考 |
| :--- | :--- | :--- |
| **スタート時エネルギー (`initEnergy`)** | 各機 $\lceil \text{initEnergy} \div P \rceil$ | デフォルト総量 **50pt**（上限5000）<br>・1人ソロ：**50pt** ／ 3人：各 **17pt** ／ 5人：各 **10pt** |
| **問題クリア時エネルギー (`clearEnergy`)** | 各機 $\lceil \text{clearEnergy} \div P \rceil$ | デフォルト総量 **25pt**（上限5000）<br>・1人ソロ：**+25pt** ／ 3人：各 **+9pt** ／ 5人：各 **+5pt** |
| **初期タイルコア (`initCore`)** | 各機 $\lceil \text{initCore} \div P \rceil$ | デフォルト総量 **0個**（上限5000・プレイ人数で分配）<br>・1人ソロ：**0個** ／ 3人：各 **0個** ／ 5人：各 **0個** |
| **エンドレス時エネルギー（毎問）** | 各機 $\lceil (N \times 5) \div P \rceil$ | エンドレスは初期エネルギーの概念がなく、Q1（$N=7$）から一貫して $\lceil 35 \div P \rceil$（ソロ35pt / 5人各7pt）を毎問付与 |
| **回答（ANSWER）コスト** | **$\lceil N \div P \rceil$ pt（固定）** | 発射ごとの累積増加なし。$N=7$ の場合、1〜5人で **`7 / 4 / 3 / 2 / 2 pt`** |
| **RANDOM SHOT（通常連射）** | 1回につき同時発射数 $K = \max(1, \lfloor \text{残破壊可能タイル} \div 200 \rfloor)$ 発（$-K\text{pt}$） | 残タイル200枚未満なら1発（$-1\text{pt}$）、400枚なら2発同時（$-2\text{pt}$） |
| **ステージクリア時コア獲得量** | 基本値 $B = \lceil \text{残破壊可能タイル} \div 25 \rceil$<br>各機獲得量 $= \lceil (B \times 5) \div P \rceil$ | **1機シングル時は通常の5倍**（例：残30枚なら $B=2 \Rightarrow$ ソロ **+💎10** / 5人 各 **+💎2**） |
| **レベル突破ボーナス (`bonusEnergy`)** | Q3 / Q6 / Q9突破時（カスタムはステージ切替時）に**人数割り＋各プレイヤー個別選択**：<br>・**⚡ エネルギー $+\lceil \text{bonusEnergy} \div P \rceil$ pt**<br>・**💎 タイルコア $+\lceil \text{bonusEnergy} \div (3 \times P) \rceil$ 個** | デフォルト総量 **50pt**（上限5000・設定変更可）<br>・5人時：各自 **+10pt** または **+💎4** を個別選択<br>・1人時：**+50pt** または **+💎17** を選択 |

### エネルギー枯渇（ゲームオーバー）判定と安全装置
- 各機体のエネルギーバッジは、所持エネルギーが `ANSWERコスト` 以下（あと1発SHOTを撃つと回答不能になるライン）になった時点で赤点滅（`.low`）して警告します。
- 全機体が `ANSWERコスト` 未満になるとエネルギー枯渇でゲームオーバーになりますが、**コアシステムON時に E. LEADER (`unitIdx === 4`) が3コア以上所持しており、CANNON変換（`💎3 ➔ +9pt`）を行えば `ANSWERコスト` に到達できる場合はゲームオーバーにならず続行可能**です。

## 3. 5機のホバーカー固有能力（CANNON ＆ SPECIAL）

| 機体ID | CYBER名 / OCEAN名 / JUNGLE名 | カラー | CANNON（コアON時：💎3 / OFF時：5pt） | SPECIAL（各問1人1回まで・1💎＝3タイル換算） |
| :--- | :--- | :--- | :--- | :--- |
| **Unit 0** | **A. PILOT** / SUB-A / SCOUT | `#00ffcc` | ランダム位置の **3×3正方形（9マス）** 即破壊 | **[SQUARE]** 指定位置中心の $\lfloor N/2 \rfloor$ 四方の正方形一括破壊（指定型・コスト $=\lceil \text{対象枚数}/3 \rceil$） |
| **Unit 1** | **B. ENGNR** / SUB-B / DRIVER | `#ff6b35` | ランダム位置の **中心＋上下左右2マス十字（9マス）** 即破壊 | **[CROSS]** 指定位置を通る幅 $\text{round}(N/7)$ の縦横十字ライン全貫通破壊（指定型・コスト $=\lceil \text{対象枚数}/3 \rceil$） |
| **Unit 2** | **C. HACKER** / SUB-C / TRACKER | `#7b5ea7` | ランダム位置の **中心＋斜め4方向2マスクロス（9マス）** 即破壊 | **[X-LINE]** 指定位置を通る幅 $\text{round}(N/7)$ の斜めX字ライン全貫通破壊（指定型・コスト $=\lceil \text{対象枚数}/3 \rceil$） |
| **Unit 3** | **D. SNIPER** / SUB-D / HUNTER | `#ff4444` | 盤面全体から **ランダム9マス** 高速連射破壊 | **[25%RND]** 指定した $\text{round}(0.7N)$ 四方の範囲内から、盤面全体の25%分の枚数を高速ランダム散弾破壊（指定型） |
| **Unit 4** | **E. LEADER** / CMD / CHIEF | `#ffcc00` | **[エナジーキャノン]** **💎3を消費し自身のエネルギー+9ptに変換**（※コアOFF時は中央渦巻き9マス破壊） | **[SPIRAL]** 中央から時計回りに未破壊タイルを渦巻き連続破壊（即発動・所持コア全消費・`所持コア×3枚` 破壊・最低25%相当コア必要） |

- **端クランプ処理**：SQUARE / CROSS / X-LINE / 25%RND および 9マスCANNONは、盤面の端を指定しても枠外にはみ出さず盤面内に収まるよう自動クランプされます。
- **未破壊フィルタ（B案採用）**：すでに破壊済みのタイルや破壊不能なツタタイル（JUNGLE）は攻撃対象およびコア消費計算から自動的に除外され、実質的に削れるタイル枚数分だけのコア（$\lceil \text{実質枚数}/3 \rceil$）を消費します。

## 4. 3つのワールドとステージ妨害ギミック (`stageHazard`)

1. **⚡ CYBER（デジタル神殿）**：
   - 妨害ギミック：各問開始時、盤面全体の **30%（切り上げ）** のタイルが耐久値2の「バリアタイル（`.tile.barrier`）」に変化。1回目の攻撃でバリアを剥がし、2回目の攻撃でタイルを破壊できます。
2. **🌊 OCEAN（深海神殿）**：
   - 妨害ギミック：その問題で有効な視覚デバフ（`ZOOM`, `BLUR`, `OFFSET`, `HUE/DESAT`, `FLIP`）の中からランダムで **2種類が +30% 強化** されます。さらに `FLIP`（反転）が強化対象に選ばれた場合は **時計回りまたは反時計回りに90°回転（`±90° ROT`）** が追加されます（※回転は全タイル破壊後も維持され、正解した瞬間に元に戻ります）。
3. **🌿 JUNGLE（密林の奥地）**：
   - 妨害ギミック：問題開始時（30秒）および **3秒ごと（27s, 24s, ..., 3sの計10回）** に、未破壊タイルの中から盤面全体の **3%（切り上げ・最大計30%）** が破壊不能な「ツタタイル（`.tile.vine`）」に変化します。
   - ツタタイル以外のすべてのタイルを破壊し終えると、即座に画像のぼかし・ズーム・反転が解除されてクリア画像を見ることができます。

## 5. Unsplash 公式API連携＆102問クレジット完全埋め込み仕様
- `DEFAULT_Q`（全102問）には、画像URLのスラッグ（`photo-xxx`）と1対1で完全一致検証された撮影者名（`author`）・プロフィールURL（`authorUrl`）・写真ページURL（`photoLink`）が事前埋め込み（方法A）されています。
- ステージクリア時およびゲームオーバー時の正解発表画面では、UTMパラメータ（`utm_source=imagine_tile&utm_medium=referral`）付きの公式帰属リンク `Photo by [Name] on Unsplash` が自動表示されます。
- 問題エディタ（方法B）では、自分の Unsplash Access Key を入力することで、日本語・英語キーワードでのライブ画像検索、ワンクリック採用時の Download Trigger API 自動通知、および `DEFAULT_Q` コード書き出しが可能です。
