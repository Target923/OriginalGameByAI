# サーチバトル 総括（2026-10-28・v12.17）

## どんなゲームか
お互いに自分の盤面へキューブ（2〜5マスの個体）を隠し、コールとアイテムで相手のキューブを探して撃破する推理対戦ゲーム。相手を全滅させたら勝ち。
- **見つける**：コールで当たりを探す（◎＝その個体への最初のヒット、○＝2回目以降、×＝外れ）。
- **絞り込む**：9種のアイテム（サーチキューブ・ライン・サイズ・シェイプ［C・L・T・Z］、ペアショット、ノードショット、バズーカ、ワープ、ステルス）で形や位置を推理する。
- **仕留める**：アンサーで個体の全マスを言い当てれば一気に撃破。外すと自分の個体を1つ差し出す。
- **トレジャー**：偶数ターンにトレジャーコール（予選4回・決勝5回）。相手が1マスに隠したトレジャーを探す。大会ではトレジャーは宝石で、見つけると相手から1つ奪う。
- 盤面は予選4×4・決勝5×5。置ける個体の数に上限はない。

## 大会モード
- あなた＋CPU3人（4人の中から毎回3人）の総当たりで、予選3試合のあと上位2名が決勝。同点は勝ち数 → 撃破マス数 → 抽選の順で決める。
- キューブ（2マス×5・3マス×4・4マス×3・5マス×2）は大会を通して持ち越し、撃破されたものは失う。
- アイテムは9種×2つ（18個）。予選は1試合で各種類1回まで。決勝は残り＋ドラフト4つ（トゥエ・モース順）。
- 持ち点は100点（80点＋宝石4つ。1つ5点）から始める。所持キューブ44マス・予選の勝利点30・宝石20をすべて失っても94点で、スピードボーナスを除けば予選でマイナスにならない。
  - 撃破したキューブのマス数を相手から奪う。
  - 勝者はさらに勝利点を奪う（予選1試合目5・2試合目10・3試合目15・決勝20）。3試合目の勝利点は1・2試合目の合計と同じで、最後まで逆転できる。
  - 予選では、早いターンで負けるとスピードペナルティで減点される（1ターン目24・21・18・15・12・9・6・8ターン目3、9ターン目から0。相手に渡さない自滅点。アンサー失敗で負けても同じ。v12.14で入れ、v12.16で自滅点化・点数改定）。
  - トレジャーは宝石。各試合に1つを置き、見つけられると相手に奪われる（1つ5点＝1試合目の勝利点と同じ）。
- 賞金は優勝者の持ち点×1万円（理論上の最高399万円）。予選1位は決勝の「先攻」か「ドラフト先行権」を選べる。
- バズーカで分解された相手の個体を失ったかどうかは、試合終了まで非公開（所持キューブの表示も試合終了まで変わらない）。
- 大会中のすべての試合（CPUどうしも）を、途中経過の画面からリプレイで見返せる（単発の試合は結果の画面から）。キューブには「相手にどこまで見破られていたか」の確率が出る。各フィールド下部にはその試合の所持キューブ状況が表示される。

## 設計の大きな転換点
1. **アイテムの整理（v5〜v11）**：強すぎるサーチオールを削除し、アッドをステルスに、ディスタンスショットをノードショットに置き換えた。バズーカは「個体を1マスキューブに分解する」攻撃アイテムに作り直した。
2. **先攻・後攻の釣り合い（v11.1）**：決勝のドラフト順をトゥエ・モース順にし、決勝の先攻勝率を41%から50%にした（単発の試合）。
3. **大会モード（v12）**：キューブ・アイテム・点の持ち越しで、1試合ごとの判断が大会全体の戦略になった。
4. **トレジャーの置き場所（v12.2）**：CPUが角に置きすぎていた（4×4で52%）のを直し、どのマスもほぼ同じ確率にした。
5. **「置いたもん勝ち」への対処（v12.5〜v12.6）**：今回いちばん大きな見直し。
   - 測定で見つかったこと：
     - 個体の数が勝率をほぼ決めていた（4×4で3個体53%→6個体75%）。
     - 購入できた頃の決勝は1人12個前後のアイテムを持つ打ち合いで、先攻が75〜90%勝っていた。
     - 残りキューブは公開なので、置き切ると組み合わせを読まれた（同じ6個体で勝率69%→47%）。
   - 対処：
     - 購入を廃止し、アイテムは2つずつ持って使い分けるようにした。
     - 生存点をやめ、持ち点の奪い合いにした。
     - 勝利点は6点固定にした（v12.7で6・9・12・15、v12.10で5・10・15・20の段階に）。
   - 結果：多く置けば撃破で奪われ、少なく置けば勝ちにくい。小さいキューブの3〜5個体がほぼ同じ収支になり、「多く置くか、少なく置くか」が本当の選択になった。予選で点を守るか、決勝にキューブを残すかの駆け引きも生まれた。
6. **宝石の奪い合いと勝利点の段階化（v12.7〜v12.10）**：トレジャーを相手から奪う宝石にし、勝利点を後の試合ほど大きくした（最終的に5・10・15・20、3試合目＝1・2試合目の合計）。3試合目で決勝の2人が入れ替わる割合が44%から約62%に上がり、最後まで逆転の目が残るようになった。
7. **サーチラインの見直し（v12.12）**：盤面が混んできて（予選は16マス中約14マスが埋まる）、マスの数だけのサーチラインはほとんど「満杯」と返す弱いアイテムになっていた。答えを「個体の数 / マスの数」（例：2個体 / 3マス）にし、CPUも個体の数を推理に使う。
8. **キューブの内訳の見直し（v12.13）**：「数を置くほど強い」と思われていたが、測り直すと3・4マスが強く、2・5マスが弱かった（予選の総当たりで 2・3・3・4・4 が平均67%、それまでの標準の 2・2・2・3・3 は39%）。CPUが4マスを使わずに余らせていたので、3・4マス中心の型からランダムに選ぶようにした（読まれないように。5マスは5%ほど）。1試合モードのCPUも同じ考え方にした。
9. **スピードペナルティ（v12.14〜v12.16）**：大差でリードしているときに2マス1個だけ置いて即負けし、キューブを温存する動きを防ぐために入れ（v12.14）、v12.15のご褒美化を経て、v12.16で「相手に渡さない自滅点（1ターン目24点〜8ターン目3点）」に改定。特定プレイヤーに点を貢ぐ利敵行為を防ぎつつ、即負け温存を抑止する。
10. **アンサーペナルティの手番終了化（v12.16）**：アンサー失敗時は自分の個体を1つ差し出すだけでなく、その手番が即終了するように変更。候補が数通りに絞られたときの「捨て身の総当たりアンサー」を防止。
12. **Z字の導入と5マスの救済（v12.17）**：
    - 5マスは数学的には12種類（ペントミノ）あるが、「キューブ」「L字」「T字」の縛りがあったため幅1マスの線状しかなく、2×2などの塊に化けられない構造的弱点（早期特定・勝率低下）を抱えていた。
    - 新カテゴリ「Z字」（Z4・偏平Z5・段差S5）を導入。特に偏平Z5（2+3）は2×2・L4・T4のすべての部分構造を内包するため、4マスアンサーを誘って返り討ちにする強力なブラフ性能を持つ。配置画面でも盤面をなぞって直感的に配置できるフリーハンド機能（自動形状判定）を搭載。
    - これに伴い、CPUの配置ロジックで5%に抑制されていた5マスの配置確率を適正化。予選（4×4）は標準20%（物量型30%、堅実型15%、温存型1・2試合目5%→3試合目30%）、決勝（5×5）は標準50%（物量型70%、温存型80%、堅実型40%）へと大幅に引き上げ、1試合モードも4×4は20%、5×5は50%に改定。
13. **操作性と視覚性の改善（2026-10-28）**：アンサー時のマス選択をドラッグ（指やマウスでなぞる操作）でも連続選択・解除できるように改善。リプレイ画面の各フィールド直下にも所持キューブUIを表示。またトレジャーチャンス中は選択マスや相手フィールドをゴールド（#D4AF37）で強調し、通常手番との視覚的差別化を強化。

## CPU
- 人間と同じ情報だけで推理する。確信できた個体だけアンサーし、外さない。
- **大会での置き方**：残りキューブと試合の段階から、置き方の型を抽選する（同じ組み合わせだと読まれるため）。予選は 2・3・3・4・4 など3・4マス中心、決勝は 3・3・3・3・4・4・4 など7個体。3・4マスが足りなければ2マス、次に5マスで埋め、5マスはZ型導入に伴い予選20%・決勝50%（物量型は予選30%/決勝70%、温存型は決勝80%など）の確率で積極的に投入する。盤面の8割以上を埋めるときは固め、それ未満は外周に散らす。
- **性格（4人から3人出場）**：
  - CPU-α 物量型（盤面を16マスまで埋める。2・3・3・4・4 や 2・2・2・3・3・4。5マスも少し多め）
  - CPU-β キューブ温存型（1・2試合目は2マスだけの3個体。3・4マスを3試合目と決勝に残す）
  - CPU-γ 堅実型（毎試合、3・4マスで4個体）
  - CPU-δ アイテム浪費型（置き方は標準）
- **アイテムの使い方**：浪費型以外は、試合ごとにバランスよく使う（1・2試合目は各種類の1つ目まで、攻撃アイテムは1試合3〜5個まで）。
- **バズーカ**：角に撃って分解し、角の隣から破片をたどる（あなたの使い方を覚えさせた）。

## いまのバランス（CPUどうしの測定）
- **キューブの内訳（v12.13）**：3・4マスが強く、2・5マスが弱い。2マスはすぐ形が決まって倒され、5マスは大きな的で形も決まりやすい。予選は 2・3・3・4・4（平均67%）・3・3・4・4（64%）、決勝は 3・3・3・3・4・4・4（62%）が強い。3・4マスは合わせて7個なので、予選で使うか決勝に残すかが大会の作戦になる。
- **性格ごとの優勝率（見本v12.14）**：標準29.0%／温存型28.2%／堅実型26.9%／浪費型25.2%／物量型14.9%（測定ごとに±4〜8%ぶれる。v12.13の見本では温存型35.9%・標準20.5%だった）。
- **先攻の勝率（見本v12.14）**：予選54.3%・決勝54.5%。
- **トレジャー（宝石）**：相手に見つけられる割合は約69%。予選1試合では、両方が奪い合って差し引き0が約半分、片方だけ奪うのが約4割。予選のあとの宝石は3〜5つが約86%。トレジャーで決勝の2人が変わるのは約13.5%（v12.6の+4点では約8%）。
- **サーチライン（v12.12）**：持たないときの勝率の下がり方は予選−10.0・決勝−13.7（マスの数だけだったときは−5.3・−1.2）。予選では中くらい、決勝では強いアイテムの仲間入り。
- **逆転（見本v12.14）**：3試合目で決勝の2人が入れ替わるのは53.5%（v17は63.0%）、2試合目の後に4位でも決勝へ進むのは13.0%、予選1勝で決勝へ進むのは16.3%。優勝者の持ち点は平均159.9点（賞金約160万円）。
- **実際に遊んだ感想**：4位でも3位と5pt・2位と約10pt差の接戦になり、トレジャーを2回落としたのが響いた（作者のプレイ）。

## 遊び方のモード
- **CPU戦**・**プレイヤーバトル**（1台で2人が交代）・**大会**（あなた＋CPU3人）・**オンライン対戦**（2026-10-25）。
- オンライン対戦は、部屋を作った人の端末が審判になり、6文字のコードで相手が入る。PeerJS の無料クラウドでつなぎ、試合のデータは端末どうしで直接やりとりする（サーバー代0円）。相手の端末には見てよい情報だけを送るので、部屋に入った側はのぞけない（部屋を作った側は、開発者ツールを使えばのぞける。知り合いどうしで遊ぶ前提）。くわしくは docs/online.md。

## 道具
- **シミュレーター**（タイトルの「シミュレーター」から開く）：CPUだけの大会を端末で何百回も回し、点数のルールを変えたときの逆転・性格の強さ・賞金を、同じ試合結果のまま数え直せる。ゲームと同じルールとCPUを使うので、ルールを変えればそのまま測れる。開発用のコマンド（tools/sim.js）も同じ中身。

## 残っている課題
- 決勝の先攻有利（CPUどうしの見本では51.5〜59.0%で、測定ごとにぶれる）。後攻に何か補償を足すか検討の余地がある。
- 厚い盤面の決勝ではCPUの考える時間が長い（7個体どうしで1試合平均3.5秒、1手番最大約3秒）。
- 性格の強さに差がある（見本v12.14：物量型14.9%が弱く、ほかは25〜29%。見本を作るたびに±4〜8%ぶれる）。3・4マスを予選で使い切る性格は決勝で2マスが多くなって弱い。決勝に4マスを1つ残すなどの工夫の余地がある。
- 5マスの救済と配置頻度の適正化（v12.17）：Z字（偏平Z5、段差S5）の導入により5マスが強力な罠ピースへ進化したため、CPUの5マス配置確率を予選20%・決勝50%（物量型や温存型の決勝は70〜80%）へ引き上げた。実戦での勝率や遭遇感を今後検証していく。2マスも弱いが、撃破されても2点と安い。
- 人間らしい駆け引き（ブラフや読み合い）を、さらにCPUに覚えさせる余地がある。
