## 残っている課題・アイデア
- 決勝の先攻有利（CPU どうしの見本で51.5〜59.0%。測定ごとにぶれる）。
- 性格の強さの差（見本 v12.14：標準29.0%・温存型28.2%・堅実型26.9%・浪費型25.2%・物量型14.9%。見本ごとに±4〜8%ぶれ、v12.13の見本では温存型35.9%・標準20.5%）。物量型がいつも弱め。案：標準・浪費型・堅実型も決勝に4マスを1つ残す、など（ユーザーと相談）。
- 5マスは今のルールでは弱い（4×4でも5×5でも、足すと勝率が下がる）。使わせたいなら、5マスの形を増やして形を決めにくくする（2×2＋1のP字など）といったルールの調整が要る（ユーザーと相談）。
- CPU の考える時間：大会の決勝は1試合約2.3秒（1手の最大1.4秒）。1試合モードの5×5は7個体どうしになって1手の最大2秒ほど（スマホではもっと長い）。
- サーチキューブは「いずれリワーク予定」。
- 人間らしい駆け引き（ブラフ・読み合い）を CPU に。
- 旧シミュレーターの artifact を消すか（ユーザーの確認待ち）。
