# 🛸 01. 『IMAGINE TILE（イマジンタイル）』完全実装仕様書＆ゲームルール

## 1. ゲーム概要とプレイモード体系
『IMAGINE TILE』は、ズーム・ぼかし・色相変化・反転・位置ズレなどの視覚デバフがかかった画像（または動画）を覆うタイル壁を、ホバーカーの武装（SHOT / CANNON / SPECIAL）で破壊し、30秒以内に隠された答えを導き出すSFクイズアクションゲームです。

### 編成スタイル（Play Style）
タイトル画面の `#playstyle-row` または5機のホバーカーアイコン（`#intro-cars`）をクリックすることで、以下の2スタイルをすべてのゲームモード（NORMAL / HYPER / ENDLESS / CUSTOM）で切り替えられます：
- **👥 5機チーム (`playStyle = 'team'`, `numPlayers = 5`)**：1人で5機のホバーカー（PILOT / ENGNR / HACKER / SNIPER / LEADER）を切り替えながら戦う標準モード。
- **👤 1機シングル (`playStyle = 'solo'`, `numPlayers = 1`)**：5機の中から好きな1機（`soloUnit = 0..4`）を選んで単独で挑むモード。エネルギーとタイルコアが1機に集中（5倍相当）するため、毎問ダイナミックにSPECIALやCANNONを撃ち込める爽快なプレイフィールを持ちます。
- **マルチプレイ拡張を見据えた内部データ構造**：
  `G.players` の各要素はスロット番号 `pi` (`0..numPlayers-1`) とは独立して `unitIdx` (`0..4`) を保持し、`getUnitIdx(pi)` を介して機体色 `PC[u]`・CANNON性能 `AREA_INFO[u]`・SPECIAL性能 `SPEC_INFO[u]` を参照します。これにより、将来2〜5人のマルチプレイを実装する際も、`G.players` の長さを参加人数（1〜5人）にするだけで全計算式と機体スキルがそのまま動作します。

### 4つのゲームモード
1. **▶ NORMAL MODE（全10問）**：
   - 盤面サイズ推移：Q1〜Q3 `7×7` (Lv1) ➔ Q4〜Q6 `8×8` (Lv2) ➔ Q7〜Q9 `9×9` (Lv3) ➔ Q10 `10×10` (FINAL / ヒント `???`)。
2. **⚡ HYPER MODE（全10問）**：
   - 盤面サイズ推移：Q1〜Q3 `8×8` (Lv2) ➔ Q4〜Q6 `9×9` (Lv3) ➔ Q7〜Q9 `10×10` (Lv4) ➔ Q10 `15×15` (CHAOS FINAL / ヒント `???` / 真っ黒パレット)。
3. **∞ ENDLESS MODE（無限ステージ）**：
   - Q1〜Q2は `7×7` から始まり、2問クリアするごとに盤面が `+1×1` 拡大（`sz = 7 + Math.floor(step / 2)`）。
   - Q9（`step >= 8`, `11×11`）から深黒パレットに突入し、Q31（`step >= 30`）以降はヒントが `???` になります。
4. **🛠 CUSTOM MODE（ステージ＆グリッドビルダー）**：
   - 最大10ステージまで、各ステージの「問題数（1〜50問）」「盤面サイズ（`1×1`〜`100×100`）」「ステージ妨害ギミック（⚡CYBER / 🌊OCEAN / 🌿JUNGLE / 🎲RANDOM / 🚫OFF）」を自由に設計可能。

## 2. エネルギー（pt）＆回答コスト＆タイルコア（💎）の数理仕様

ゲーム内のすべてのリソースは **「1💎（タイルコア） ＝ 3pt（エネルギー） ＝ 3タイル破壊」** の完全等価レートで設計されています。

| リソース・コスト項目 | 数式（プレイ人数 $P \in \{1..5\}$、盤面一辺 $N$） | デフォルト値・備考 |
| :--- | :--- | :--- |
| **スタート時エネルギー (`initEnergy`)** | 各機 $\lceil 	ext{initEnergy} \div P ceil$ | デフォルト総量 **50pt**（上限1000）<br>・1人ソロ：**50pt**<br>・5機チーム：各 **10pt**（計50pt） |
| **問題クリア時エネルギー (`clearEnergy`)** | 各機 $\lceil 	ext{clearEnergy} \div P ceil$ | デフォルト総量 **25pt**（上限1000）<br>・1人ソロ：**+25pt**<br>・5機チーム：各 **+5pt**（計25pt） |
| **エンドレス時エネルギー（毎問）** | 各機 $\lceil (N 	imes 5) \div P ceil$ | エンドレスは初期エネルギーの概念がなく、Q1（$N=7$）から一貫して $\lceil 35 \div P ceil$（ソロ35pt / 5機各7pt）を毎問付与 |
| **回答（ANSWER）コスト** | **$\lceil N \div P ceil$ pt（固定）** | 発射ごとの累積増加なし。$N=7$ の場合、1〜5人で **`7 / 4 / 3 / 2 / 2 pt`** |
| **RANDOM SHOT（通常連射）** | 1回につき同時発射数 $K = \max(1, \lfloor 	ext{残破壊可能タイル} \div 200 floor)$ 発（$-K	ext{pt}$） | 残タイル200枚未満なら1発（$-1	ext{pt}$）、400枚なら2発同時（$-2	ext{pt}$） |
| **ステージクリア時コア獲得量** | 基本値 $B = \lceil 	ext{残破壊可能タイル} \div 25 ceil$<br>各機獲得量 $= \lceil (B 	imes 5) \div P ceil$ | **1機シングル時は通常の5倍**（例：残30枚なら $B=2 \Rightarrow$ ソロ **+💎10** / 5機 各 **+💎2**） |
| **レベル突破ボーナス (`bonusEnergy`)** | Q3 / Q6 / Q9突破時（カスタムはステージ切替時）に選択：<br>・**⚡ エネルギー $+	ext{bonusEnergy}$ pt**<br>・**💎 タイルコア $+\lceil 	ext{bonusEnergy} \div 3 ceil$ 個** | デフォルト **15pt** または **💎5**（$15	ext{pt} = 5	ext{💎} 	imes 3$ の等価選択式） |

### エネルギー枯渇（ゲームオーバー）判定と安全装置
- 各機体のエネルギーバッジは、所持エネルギーが `ANSWERコスト` 以下（あと1発SHOTを撃つと回答不能になるライン）になった時点で赤点滅（`.low`）して警告します。
- 全機体が `ANSWERコスト` 未満になるとエネルギー枯渇でゲームオーバーになりますが、**コアシステムON時に E. LEADER (`unitIdx === 4`) が3コア以上所持しており、CANNON変換（`💎3 ➔ +9pt`）を行えば `ANSWERコスト` に到達できる場合はゲームオーバーにならず続行可能**です。

## 3. 5機のホバーカー固有能力（CANNON ＆ SPECIAL）

| 機体ID | CYBER名 / OCEAN名 / JUNGLE名 | カラー | CANNON（コアON時：💎3 / OFF時：5pt） | SPECIAL（各問1人1回まで・1💎＝3タイル換算） |
| :--- | :--- | :--- | :--- | :--- |
| **Unit 0** | **A. PILOT** / SUB-A / SCOUT | `#00ffcc` | ランダム位置の **3×3正方形（9マス）** 即破壊 | **[SQUARE]** 指定位置中心の $\lfloor N/2 floor$ 四方の正方形一括破壊（指定型・コスト $=\lceil 	ext{対象枚数}/3 ceil$） |
| **Unit 1** | **B. ENGNR** / SUB-B / DRIVER | `#ff6b35` | ランダム位置の **中心＋上下左右2マス十字（9マス）** 即破壊 | **[CROSS]** 指定位置を通る幅 $	ext{round}(N/7)$ の縦横十字ライン全貫通破壊（指定型・コスト $=\lceil 	ext{対象枚数}/3 ceil$） |
| **Unit 2** | **C. HACKER** / SUB-C / TRACKER | `#7b5ea7` | ランダム位置の **中心＋斜め4方向2マスクロス（9マス）** 即破壊 | **[X-LINE]** 指定位置を通る幅 $	ext{round}(N/7)$ の斜めX字ライン全貫通破壊（指定型・コスト $=\lceil 	ext{対象枚数}/3 ceil$） |
| **Unit 3** | **D. SNIPER** / SUB-D / HUNTER | `#ff4444` | 盤面全体から **ランダム9マス** 高速連射破壊 | **[25%RND]** 指定した $	ext{round}(0.7N)$ 四方の範囲内から、盤面全体の25%分の枚数を高速ランダム散弾破壊（指定型） |
| **Unit 4** | **E. LEADER** / CMD / CHIEF | `#ffcc00` | **[エナジーキャノン]** **💎3を消費し自身のエネルギー+9ptに変換**（※コアOFF時は中央渦巻き9マス破壊） | **[SPIRAL]** 中央から時計回りに未破壊タイルを渦巻き連続破壊（即発動・所持コア全消費・`所持コア×3枚` 破壊・最低25%相当コア必要） |

- **端クランプ処理**：SQUARE / CROSS / X-LINE / 25%RND および 9マスCANNONは、盤面の端を指定しても枠外にはみ出さず盤面内に収まるよう自動クランプされます。
- **未破壊フィルタ（B案採用）**：すでに破壊済みのタイルや破壊不能なツタタイル（JUNGLE）は攻撃対象およびコア消費計算から自動的に除外され、実質的に削れるタイル枚数分だけのコア（$\lceil 	ext{実質枚数}/3 ceil$）を消費します。

## 4. 3つのワールドとステージ妨害ギミック (`stageHazard`)

1. **⚡ CYBER（デジタル神殿）**：
   - 妨害ギミック：各問開始時、盤面全体の **30%（切り上げ）** のタイルが耐久値2の「バリアタイル（`.tile.barrier`）」に変化。1回目の攻撃でバリアを剥がし、2回目の攻撃でタイルを破壊できます。
2. **🌊 OCEAN（深海神殿）**：
   - 妨害ギミック：その問題で有効な視覚デバフ（`ZOOM`, `BLUR`, `OFFSET`, `HUE/DESAT`, `FLIP`）の中からランダムで **2種類が +30% 強化** されます。さらに `FLIP`（反転）が強化対象に選ばれた場合は **時計回りまたは反時計回りに90°回転（`±90° ROT`）** が追加されます（※回転は全タイル破壊後も維持され、正解した瞬間に元に戻ります）。
3. **🌿 JUNGLE（密林の奥地）**：
   - 妨害ギミック：問題開始時（30秒）および **3秒ごと（27s, 24s, ..., 3sの計10回）** に、未破壊タイルの中から盤面全体の **3%（切り上げ・最大計30%）** が破壊不能な「ツタタイル（`.tile.vine`）」に変化します。
   - ツタタイル以外のすべてのタイルを破壊し終えると、即座に画像のぼかし・ズーム・反転が解除されてクリア画像を見ることができます。

## 5. Unsplash 公式API連携＆102問クレジット完全埋め込み仕様
- `DEFAULT_Q`（全102問）には、画像URLのスラッグ（`photo-xxx`）と1対1で完全一致検証された撮影者名（`author`）・プロフィールURL（`authorUrl`）・写真ページURL（`photoLink`）が事前埋め込み（方法A）されています。
- ステージクリア時およびゲームオーバー時の正解発表画面では、UTMパラメータ（`utm_source=imagine_tile&utm_medium=referral`）付きの公式帰属リンク `Photo by [Name] on Unsplash` が自動表示されます。
- 問題エディタ（方法B）では、自分の Unsplash Access Key を入力することで、日本語・英語キーワードでのライブ画像検索、ワンクリック採用時の Download Trigger API 自動通知、および `DEFAULT_Q` コード書き出しが可能です。
