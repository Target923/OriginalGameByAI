# 「？」マーク（新しいステルスの記号）の試作

ステルスを付けたキューブへの最初のヒットに出す記号。◎と○を斜めのくねくねした境界で分け、境界を煙のようにぼかす（2026-10-29 ユーザーの案「二つのマークの境界線にブラーをかけ、煙のような境界線」）。

- `gen.py`：境界線（くねくね）の座標を計算して `paths.js` に書き出す。中心付近は左上へふくらませて○の点を○側に残し、外の輪と交わるところは直径の近くを通して、◎と○が半分ずつに見えるようにしている。
- `qm.js`：SVG の部品（defs：マスク・フィルター）と、各案の記号を返す。外の輪は◎・○とも半径14にそろえる（違う半径だと境界で段差に見える）。
  - H：くねくね＋ぼかしだけ
  - I：境界を煙のように乱し（feTurbulence＋feDisplacementMap）、白い煙（薄いもや＋細い筋）を重ねる
  - J：I の煙を◎と○の色にする
  - K：I の煙をゆっくり揺らす（SMIL の animate で、ノイズを少しずつずらす）
- 本番に入れるときは、defs を template.html の共通の `<svg><defs>`（#g-metal と同じ場所）に置く（マスクやフィルターの id がマスごとに重複しないように）。

## 2案目（2026-10-29 ユーザーの案。こちらで進める）

煙の境界の案（H〜K）は「意外と見づらい」ため、新しい形にした。

- ◎の二重丸（半径14と7.6）に、○の中心の点（半径2.3）を重ねる。
- ◎の飛び出した線（4本）を3本にする：真上に1本、そこから120度おきに2本（右下・左下）。線は半径12.4〜17.4（◎と同じ長さ）。
  `M20 2.6v5M35.07 28.7 30.74 26.2M4.93 28.7 9.26 26.2`
- 色はミディアムターコイズ #48D1CC（光も同じ色）。
- 自分フィールドでは、色の近いキューブ（ミント #39E0B4・シアン #4FE3FF）の上で見えにくいので、暗い縁取り（同じ形を rgba(3,6,14,.5)・太さ4.6で下に敷く）を付ける案をユーザーに見せた。暗い背景（相手フィールド）では縁取りは見えないので、どこでも付けてよい。
- ユーザーの希望で、縁取りの代わりにドロップシャドウを試した（2026-10-29）。
  - S1（少し下へ落とす影）：`filter: drop-shadow(0 1px 1.5px rgba(0,0,0,.9)) drop-shadow(0 0 4px #48D1CC)`
  - S2（周りを囲む濃い影）：`filter: drop-shadow(0 0 1.2px rgba(0,0,0,.95)) drop-shadow(0 1px 2.5px rgba(0,0,0,.8)) drop-shadow(0 0 4px #48D1CC)`
  - 暗い相手フィールドでは影は見えず、見た目は変わらない。
- 決定：S1（少しの影）を、この記号だけでなく全部のマーク（◎・○・×・ノード・◎の番号）に付けた（template.html の `--mk-shadow`）。
