# サーチバトルの文言（編集用）

ゲームの画面に出る文言を、画面ごとに4つのファイルに分けて書き出したものです。
ここで書き換えた文言を、ソースに書き戻してゲームに反映します。

| ファイル | 中身 | おすすめの順番 |
| --- | --- | --- |
| 1_ルールとアイテム.json | ルール画面、アイテムとキューブの名前と説明 | 1（遊ぶ人がいちばん読む） |
| 2_タイトル・配置・対戦.json | タイトル、キューブの配置、ドラフト、対戦中の案内、演出の文字、エラーの知らせ | 2 |
| 3_ログ・結果・大会.json | 対戦ログ、試合の結果、リプレイ、大会の画面と順位表、CPU の性格 | 3 |
| 4_シミュレーター・オンライン.json | シミュレーター画面、オンライン対戦のロビーと知らせ | 4（ふだん目にしない画面） |

## 書き換えかた

- 書き換えるのは各項目の **text だけ** です。ほかの項目は書き戻しに使うので、変えないでください。
  - id・line：ソースの中の場所
  - where：その文言がコードのどこにあるかの目安（例：renderTitle＝タイトル画面、dockHTML › case answer＝アンサーの操作欄）
  - h：書き出したときの文の確認用
- **{{1}}・{{2}}** は、名前や数などの差し込みです（中身は vars）。文の中で順番を入れ替えてもかまいませんが、消したり増やしたりはできません。
- **around** は、1つの文が差し込みで分かれているときの前後の文です。「…」は別の項目か差し込みです。どの文の一部かを見る手がかりにしてください。
- 引用符・改行・「<」などは、書き戻すときに自動で正しい形に直すので、そのまま書いてかまいません。
- 同じ文言がいくつもの場所にあることがあります（「キャンセル」など）。直したい場所だけ直せます。
- 形の分類の名前（R型・L型・T型・Z型）は、プログラムが形を見分けるのにも使っているので、そのものだけの文字は入れていません（文の中に出てくるものは書き換えられます）。

## 書き戻しかた（Claude などに頼むとき）

```
node tools/texts.js apply texts          # このフォルダの JSON を全部まとめて書き戻す（変わった text だけ）
node tools/texts.js apply texts --dry    # 試し（何件書き戻すかだけ出す）
node tools/texts.js extract              # ソースから書き出し直す（このフォルダの JSON を作り直す）
```

- 書き出したあとにソースが変わると、その周りの文言は位置が合わなくなり、書き戻せません（「場所が合いません」と出ます）。編集中にほかの変更を入れるときは、先に書き戻してください。
- JS の読み取りに acorn を使います（`npm i acorn acorn-walk`）。
